- **되돌리기**: 저장마다 `prepEvs`가 저장 전후를 비교해 첫 기록에 `chg`(바뀐 cage·litter·값의 전후)와 묶음 id `grp`를 붙임. 토스트 [되돌리기] 10초 (대화창 열려 있으면 대화창 안에 띄움). `undoSave`는 chg 전 상태로 돌리는데, 그 사이 같은 cage를 다른 저장이 바꿨으면 막음. 기록은 `되돌림` 타입 + `undoOf`, 원래 기록은 줄 그어 표시 (원래 기록 문서는 수정 안 함 → Firestore events update 권한 필요 없음). 기록 수정 창에도 '이 저장 되돌리기'. `starAgent.apply` 결과에 `undo`, `starAgent.undo(id)` 추가.
- **기록 없는 상태 변경 막기**: Store.commit(Firestore·데모)과 editEvent(mut 있을 때)가 모두 `prepEvs`를 거침 → 기록이 비어 있어도 상태가 바뀌면 `상태 변경` 기록(입력자, 바뀐 내용)이 자동으로 남음. 기록 탭에 '▸ 바뀐 것'으로 chg 내용 표시. 백업 되돌리기 기록에 바뀐 내용 요약, 초기 데이터(seed)도 기록 남김. 코드상 commit에 빈 기록을 보내는 경로는 없었음 → FAH 1-D·1-E 새끼는 출산 기록을 지웠거나(기록 삭제) Firestore 콘솔에서 고친 경우로 추정. 기록 탭에서 FAH 1-D '기록 삭제'를 찾아보면 확인 가능. 앞으로 같은 일은 '출산 기록 없음' 할 일로 뜸.
- **DOB 카드**: 제목 `♀ DOB / ♂ DOB` (같으면 `♀♂ DOB`, Mating이면 수컷 원래 cage litter DOB), cage id 작게. 같은 line·같은 라벨 DOB cage가 여럿이면 `라벨에 1-D 적기`. Mating cage에 `♂ 1 (from FAH 1-A · DOB …)`, 원래 cage에 `Mating 나감 ♂1 → …`. 케이지 탭 검색칸: 26.04.06 · 260406 · 0406 · 4/6, 글자가 있으면 cage id·이름 검색.
